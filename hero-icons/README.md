# hero-icons（不在 repo 裡）

英雄方形圖示與英雄清單是 Riot Games 的素材，不放進這個 repo。自己下載到這個資料夾：

```bash
python tools/fetch_ddragon_icons.py           # 版本預設 16.20.1
```

會產生 `hero-icons/16.20.1_champion.json`（英雄清單，`tools/archive.py` 用來對英雄名稱）和 `hero-icons/16.20.1/<英雄>.png`（禁用辨識用的方形圖示）。

---

Champion icons and the champion list belong to Riot Games and are not in this repo. Download them with `python tools/fetch_ddragon_icons.py`.
